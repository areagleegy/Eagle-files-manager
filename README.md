# Eagle Files Manager

Offline-first Android file manager for **Android 14 (API 34) and newer**.

Arabic documentation: [README_AR.md](README_AR.md)

Features include local file operations, image viewing, audio/video playback, PDF and text reading, and ZIP create/extract tools. The app intentionally does not request Android's `INTERNET` permission.

GitHub Actions builds a debug APK and publishes it as the artifact `eagle-files-manager-android14plus-debug-apk` after a successful workflow run.
